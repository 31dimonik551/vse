# Мила, Тёма и Бублик 🌼

Развивающий мультик для малышей **2+**: добрый, яркий, с **мягкими медленными переходами**
(без резких смен кадров и мельканий — это важно для маленьких глаз).

Всё нарисовано **кодом** (SVG-графика + плавная CSS/JS-анимация) и озвучено **синтезом речи**,
поэтому серия открывается прямо в браузере — на компьютере, телефоне или планшете.

> **Статус:** пилотная серия-демо. Короткая, чтобы показать стиль и подачу.
> Дальше серии можно удлинять и добавлять новые.

---

## 🎬 Как посмотреть

1. Скачайте репозиторий (или откройте файл `index.html`).
2. Двойной клик по **`index.html`** — серия откроется в браузере.
3. Нажмите большую кнопку **«Начать»** и смотрите со звуком 🔊.

Ничего устанавливать не нужно — файл полностью автономный.

### Управление (для родителей)
| Кнопка | Действие |
|---|---|
| ◀ Назад | предыдущая сцена |
| ⏸ Пауза / ▶ Играть | остановить/продолжить |
| Дальше ▶ | следующая сцена |
| 🔊 Звук | включить/выключить речь и музыку |
| 🎙️ Голос | выбрать голос озвучки (и сразу послушать) |

Также работают клавиши: **←/→** — листать сцены, **пробел** — пауза.

### Про озвучку и «красивый голос»
Голос берётся из **синтеза речи вашего устройства/браузера** (Web Speech API).
Приложение само выбирает самый качественный доступный голос (нейросетевой), а
кнопкой **🎙️ Голос** можно переключиться на любой другой и сразу его услышать.
Где голоса самые приятные:
- **Android / Chrome** — «Google русский» (обычно уже стоит).
- **iPhone / iPad** — Настройки → Универсальный доступ → Устный контент →
  Голоса → Русский → скачать **«Милена (улучшенный/премиум)»**.
- **Windows / Edge** — нейро-голоса «Microsoft Svetlana/Dmitry (Natural)».

> Полностью «студийную» озвучку (готовый аудиофайл) в этой песочнице сделать
> нельзя — внешние нейро-сервисы (Google, Microsoft, и т. п.) заблокированы
> сетевой политикой. Поэтому озвучка звучит настолько хорошо, насколько
> позволяет выбранный голос устройства.

## 📖 Серия 1 — «Прогулка по солнечной полянке»

Герои — девочка **Мила**, мальчик **Тёма** и щенок **Бублик** — идут гулять и
по дороге понемногу узнают мир. Восемь спокойных сцен затрагивают все четыре темы:

| Сцена | Тема | Чему учит |
|---|---|---|
| 1. Привет | доброта | приветствие, знакомство |
| 2. Солнышко | природа | небо, солнце, слово «солнышко» |
| 3. Цветы | **цвета** | красный · жёлтый · синий |
| 4. Считаем | **цифры** | счёт 1 · 2 · 3 |
| 5. Зайчик | **животные** | заяц, как прыгает, поздороваться |
| 6. Буква А | **буквы** | буква А → **а**рбуз |
| 7. Круг | **формы** | круг (солнышко и арбуз круглые) |
| 8. До свидания | доброта | повторение, похвала, прощание |

## 🧩 Как устроено (для тех, кто будет развивать)

Вся серия — один автономный файл `index.html`. Логика простая и «датафицированная»:

- **Сцена** описывается объектом в массиве `scenes` внутри `<script>`:
  ```js
  { show:["pRed","pYellow","pBlue"],   // какие предметы показать в этой сцене
    cap:"Красный · Жёлтый · Синий",    // крупная подпись-слово внизу
    say:"На полянке расцвели цветы…" } // текст, который проговаривает голос
  ```
- **Предметы** (цветы, цифры, зайчик, буква, арбуз…) нарисованы в SVG и помечены
  классом `scene-prop` с уникальным `id`. Движок показывает нужные плавным
  проявлением, остальные прячет — так получаются мягкие переходы без склеек.
- **Фон и герои** (небо, солнце, облака, дерево, Мила, Тёма, Бублик, бабочка)
  присутствуют всегда и тихо «дышат»/качаются за счёт медленных CSS-анимаций.
- **Озвучка** — Web Speech API (`ru-RU`): голоса ранжируются (`scoreVoice`), лучший
  выбирается автоматически, текст читается по предложениям с мягкими паузами.
  **Музыка** — мягкие тоны на Web Audio API; её громкость автоматически приглушается,
  пока говорит голос.

### Добавить новую сцену
1. Нарисуйте новый предмет в SVG и дайте ему `class="scene-prop"` и уникальный `id`.
2. Добавьте объект сцены в массив `scenes` (`show`, `cap`, `say`).
Готово — точки-индикаторы и счётчик «Сцена X / N» подстроятся сами.
