# Раскадровка: «Пип потерялся ночью и находит дорогу домой по светлячкам»

9 кадров для мультика про лисёнка Пипа. Каждый блок — самодостаточный промпт
для Nano Banana (вставлять по одному). Сначала генерь кадр 1, дальше можно
дописывать «same fox Pip, now…» к нему для лучшей консистентности.

Арка: потерялся → страх → грусть → первый светлячок → чудо → идёт за ними →
тропа света → увидел дом → дома в тепле.

---

## Как собрать мультик из кадров
- Целевой хронометраж ~25–35 сек, ~3 сек на кадр.
- Приноси готовые PNG сюда — соберу видео (ffmpeg): плавные кросс-фейды между
  кадрами, лёгкий эффект Кена Бёрнса (медленный зум/пан), затемнения в начале/конце.
- Для большей плавности можно сгенерировать промежуточные позы (например, между
  кадрами 6 и 7 — ещё пара шагов).
- Музыка/звук: могу добавить нежную фоновую дорожку и звук ночного леса.
